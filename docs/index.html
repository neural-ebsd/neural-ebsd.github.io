Diffraction gradient field S(x,y)

      
S = ‖∇(x,y)A‖F = √( Σr [ (∂Ar/∂x)² + (∂Ar/∂y)² ] )

      
Computed live from the SIREN Jacobian by forward-mode differentiation — the same
        analytic formula used for the precomputed field, evaluated exactly at the probe.
